# Garbage-Classification-12-classes
Система автоматизованого контролю сортування відходів засобами глибокого навчання.

Цей проєкт є програмною реалізацією курсової роботи на тему "Метод автоматизованого контролю сортування відходів засобами глибокого навчання". Система використовує згорткову нейронну мережу ResNet50 із застосуванням трансферного навчання (Transfer Learning) для класифікації побутового сміття на 12 категорій та вбудовану базу знань для надання інструкцій щодо правильної утилізації.

## 🚀 Основний функціонал
* **Попередня обробка зображень:** автоматичне масштабування (224×224) та нормалізація вхідних фотографій.
* **Класифікація відходів:** розпізнавання 12 категорій (`batteries`, `biological`, `brown-glass`, `cardboard`, `clothes`, `green-glass`, `metal`, `paper`, `plastic`, `shoes`, `trash`, `white-glass`).
* **Оцінка впевненості:** обчислення ймовірності прогнозу нейронної мережі за допомогою функції активації Softmax.
* **База знань:** автоматичне зіставлення розпізнаного класу з відповідним кольором контейнера та рекомендаціями щодо утилізації.
* **Вебінтерфейс:** зручна взаємодія з користувачем на базі фреймворку Streamlit.

## 📊 Результати тестування моделі
Оцінювання проведено на наборі даних **Garbage Classification (12 classes)** (15 515 зображень):
* **Загальна точність (Accuracy):** `96%`
* **Середня F1-міра (Macro avg F1-score):** `0.94`
* **Середній час інференсу (CPU):** `~0.18 с`
